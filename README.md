# Odd-Even Game

A fun number game focused on odd and even numbers.

## Overview
This project is a small browser-based game built around identifying odd and even numbers.

## Files
- `index.html` – game structure
- `style.css` – styling
- `script.js` – game logic

## How to run
Open `index.html` in a browser to play the game.
